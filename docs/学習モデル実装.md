# 学習モデル実装

更新日: 2026-08-13

## 目的

月次の評価日時点で利用可能だった価格・決算情報から、6か月後・12か月後の銘柄間順位を予測する。
最初のモデルは説明可能で依存ライブラリの少ないRidge回帰とし、現在のRule Rankを同じテスト期間で
比較する。自動売買や期待収益率の断定を目的としない。

## 入力データ

`monthly_pit_v1` は、現在のTOPIX 500相当492銘柄を固定Universeとして、2016-08から月次で再構築する。

- 評価日: その月のDB内最終取引日
- Cutoff: 評価日23:59:59 JST
- 価格特徴量: 1/3/6/12Mリターン、12-1Mモメンタム、20/60日ボラティリティ、下方ボラティリティ、最大Drawdown、52週高値距離、売買代金
- 財務特徴量: PER、PBR、ROE、自己資本比率、営業利益率、売上・営業利益・EPS成長率、会社予想EPS修正、財務充足率
- ラベル開始: 評価日の翌取引日
- ラベル終了: 評価日から6/12暦月後の最初の取引日
- リターン: Yahoo調整後終値ベースの総収益近似

価格rawには変更を加えず、`price_clean_v1`の派生価格だけを使う。無効価格や10暦日超の空白をまたぐ
特徴量・ラベルは作らない。財務は評価日以前に開示された行だけを使う。

## モデル

各評価月の特徴量を銘柄横断パーセンタイルへ変換し、欠損を中立値0.5で補う。目的変数は各月の
6M/12Mリターンからその月の中央値を引いた相対リターンである。Ridgeの正則化係数は候補
`0.1, 1, 10, 100, 1000`から検証期間の平均Spearman Rank ICで選ぶ。

期間は時系列で学習・検証・テストに分ける。学習行のラベル終了日は検証開始より前、検証行の
ラベル終了日はテスト開始より前でなければならない。これにより6M/12M先の結果を境界越しに
参照するリークを防ぐ。選択後、テスト開始以前でラベルが確定した行だけを再学習して、最後の
期間外テストを1回評価する。


## 画面の見方

Streamlitの「学習モデル」タブは、次の順に表示する。

1. 使用データ: 株価、決算、対象銘柄と取得元
2. 学習する答え: 月末翌取引日から6M/12M後までの相対リターン
3. モデル: Ridge回帰で銘柄間の相対順位を算出
4. 使用できたデータ量: 行数、銘柄数、評価月、ラベル数、財務充足率
5. 過去データでの成績: 学習モデルと既存Rule Rankを同一期間で比較
6. 主要係数: どの入力が順位を上げ下げする方向だったか
7. 現在の候補順位: モデル順位、既存順位、PER、PBR、ROE

画面の「相対スコア」は同月中央値を0としたモデル出力であり、期待収益率や目標株価ではない。
係数の符号も因果関係を意味しない。

## 成果物

- DB `model_training_dataset`: 再現可能な月次特徴量・ラベル
- DB `trained_models`: 係数、前処理、分割日、評価値
- DB `model_predictions`: テスト予測と最新月予測
- `poc/output/training/monthly_pit_v1.parquet`: 学習表
- `poc/output/models/<run>/<horizon>/model.json`: モデル一式
- 同 `metrics.json`: モデルとRule Rankの比較
- 同 `coefficients.csv`: 標準化後の係数と絶対値
- 同 `predictions.parquet`: テスト・最新月の予測順位

## 評価指標

- `mean_spearman_ic`: 月ごとの予測順位と実現リターン順位の相関平均。高い方がよい
- `positive_ic_rate`: ICが正だった月の比率
- `top_decile_return`: 予測上位10%の将来リターン平均
- `top_decile_excess`: 上位10%と同月Universe平均の差
- `top_decile_excess_win_rate`: 上位10%がUniverse平均を上回った月の比率
- `long_short_spread`: 上位10%と下位10%のリターン差
- `mean_top_decile_turnover`: 前月上位10%から入れ替わった比率

6M/12Mのリターン窓は月ごとに重複するため、各月の値を独立な年率収益とは解釈しない。
売買コスト、配当税、約定可能性、TOPIX超過、業種中立化は未反映である。

## 初回実測

`monthly_pit_v1` は58,074行、492銘柄、121評価月で、6Mラベル51,300行、12Mラベル45,511行。
財務特徴量が存在する行は97.68%だった。時点整合性検査では価格日・決算開示日の将来参照、
評価日以前のラベル開始、ラベル日付の逆転はいずれも0行だった。

初回の期間外テストではRidgeがRule Rankを上回ったが、これは現在Universe固定による生存者バイアスを
含むPoC結果である。過去Universe、TOPIX/業種超過ラベル、売買コスト、複数期間のWalk-forwardを
実装するまではChampionへの昇格や運用判断に使わない。
