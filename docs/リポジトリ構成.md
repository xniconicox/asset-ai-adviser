# リポジトリ構成

更新日: 2026-08-13

## 方針

`poc`は名称を維持するが、実体は現在の開発アプリケーションルートとして扱う。仮想環境、DB、
取得原文、公開Snapshot、学習成果物はGitへ登録せず、コード・テスト・運用スクリプト・設計文書を
管理対象とする。

```text
asset-ai-adviser/
├── docs/                         設計・運用・評価文書
├── poc/                          Pythonアプリケーションルート
│   ├── src/asset_poc/            実装
│   ├── tests/                    自動テスト
│   ├── scripts/                  定期実行・バックアップ
│   ├── data/                     DB、raw、公開Snapshot（Git対象外）
│   ├── output/                   生成成果物（Git対象外）
│   │   ├── training/             Point-in-Time学習表
│   │   ├── models/               モデル、評価値、係数、予測
│   │   ├── pdf/                  現行サマリと日付別PDF・JSON
│   │   └── evaluations/          定性評価CSV/XLSX/画像
│   ├── pyproject.toml            依存関係・CLI定義
│   └── README.md                 開発入口
└── .gitignore                    ローカルデータ・生成物の除外
```

## 実行場所

コマンドは`poc`をカレントディレクトリとして実行する。

```bash
cd /mnt/c/Users/ShunK/works/asset-ai-adviser/poc
source .venv/bin/activate
asset-poc status
streamlit run src/asset_poc/app.py
```

## データと成果物

- `poc/data/raw/`: 取得した原文。クリーニングで上書きしない
- `poc/data/poc.duckdb`: ローカルDB。派生特徴量・学習表も含む
- `poc/data/published/`: StreamlitのRule Rank用公開Snapshot
- `poc/output/training/`: 学習用Parquet
- `poc/output/models/`: Streamlitの比較・評価タブが読む最新の完全な6M/12M run
- `poc/output/pdf/`: 現行サマリと`daily/YYYY/MM/`の日付別PDF・SHA-256付きJSON
- `poc/output/evaluations/`: LLM定性評価の成果物

画面はRule Rankについて公開Snapshotを読み、比較・評価タブについて`poc/output/models/`の最新完全runを
読む。DBへ直接接続しないため、取得・publish処理中のDuckDBロックと競合しない。
日次レポートは最新公開特徴量へ保存モデルを適用して作り、OneDrive同期フォルダへコピーする。
GitやDBへPDF本体を登録しない。

## Gitへ含めないもの

`.venv`、`.env`、DuckDB、raw、公開Parquet、バックアップ、ログ、`poc/output`、`tmp`、キャッシュ、
編集バックアップ`*.orig`は`.gitignore`で除外する。モデルや評価成果物を配布する場合は、Gitへ直接
追加せず、別のArtifact保管先を用意する。
