# データ取得方針

更新日: 2026-08-13

## 方針

個人利用を前提に、初月だけJ-Quants Standardで取得可能な約10年の財務履歴をローカルへ保存する。
以後の適時開示はTDnet、株価はYahoo Financeを日次取得する。取得済みrawは変更せず、取得日時、URL、
ハッシュを残して派生DBと特徴量を再生成できるようにする。

| データ | 初回 | 定常運用 | 保存先 |
|---|---|---|---|
| 財務サマリー | J-Quants Standardで全対象をバックフィル | J-Quants Freeは遅延補完 | `financial_summaries`、`raw/jquants_v2/` |
| 適時開示 | TDnet直近取得可能期間を回収 | 毎日、前日までをCatch-up | `tdnet_documents`、`raw/tdnet/` |
| 株価 | Yahoo Finance `period=max` | 毎営業日差分 | `secondary_prices`、`raw/yahoo_finance/` |
| 定性構造化 | 未構造化文書だけ | 週次または必要時 | `qualitative_analyses` |

## 初月の実行

```bash
asset-poc build-watchlist
asset-poc collect-yahoo --period max
asset-poc backfill-financials --min-periods 40 --requests-per-minute 30
asset-poc analyze-price-quality
asset-poc publish
```

`--min-periods`は取得件数ではなく、再取得対象を選ぶ既存開示日数の閾値である。確実に全対象を
再取得する必要がある場合だけ`--force`を使う。完了後に銘柄数、期間、重複、項目充足率を確認してから
Standard契約を終了する。

## 日次処理

`asset-poc daily`でTDnet、Yahoo、J-Quants遅延補完、特徴量、Rule Rank、品質検査、公開を実行する。
TDnet無料Webの取得可能期間は短いため、PC停止後も31日以内にCatch-upする。LLM構造化とモデル再学習は
日次処理へ含めず、費用と評価結果を確認して別実行する。

## 価格の利用規則

- PER、PBR、時価評価: 当時の未調整終値 `valuation_price`
- リターン、モメンタム、6M/12Mラベル: 調整後終値 `return_price`
- 元の`close`と`adjusted_close`は変更しない

この規則を`price_clean_v2_dual_price`、`price_v3_dual_price`、
`monthly_pit_v2_unadjusted_valuation`のVersionで固定する。
